# pySearch

A small command-line tool that searches Bing Images for a phrase and saves
the results into a local folder.

## Requirements

- Python 3

Install the dependencies:

```sh
pip install -r requirements.txt
```

## Usage

```sh
python main.py
```

Enter a search phrase when prompted. Matching images are downloaded to
`images/<Your-Phrase>/`.
